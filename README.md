# 🤖 Quotex Signal Bot

Quotex ট্রেডিং প্ল্যাটফর্মের জন্য উন্নত সিগনাল এবং স্বয়ংক্রিয় ট্রেডিং বট।

## ✨ বৈশিষ্ট্য

✅ **উন্নত সূচক**
- সিম্পল মুভিং এভারেজ (SMA)
- আপেক্ষিক শক্তি সূচক (RSI)
- MACD (মুভিং এভারেজ কনভার্জেন্স ডাইভার্জেন্স)
- বলিঞ্জার ব্যান্ডস
- স্টোকাস্টিক অসিলেটর

✅ **ঝুঁকি ব্যবস্থাপনা**
- দৈনিক ক্ষতি সীমা
- সর্বোচ্চ ট্রেড সংখ্যা
- স্টপ লস এবং টেক প্রফিট ক্যালকুলেশন
- অবস্থান আকার ম্যানেজমেন্ট

✅ **বিজ্ঞপ্তি সিস্টেম**
- টেলিগ্রাম রিয়েল-টাইম বিজ্ঞপ্তি
- ট্রেড আপডেট
- দৈনিক রিপোর্ট
- ত্রুটি সতর্কতা

✅ **লগিং এবং বিশ্লেষণ**
- বিস্তারিত ট্রেড লগ
- কর্মক্ষমতা পরিসংখ্যান
- সম্পূর্ণ অডিট ট্রেইল

## 📋 প্রয়োজনীয়তা

- Python 3.8+
- Quotex API অ্যাক্সেস
- টেলিগ্রাম বট (ঐচ্ছিক, বিজ্ঞপ্তির জন্য)

## 🚀 দ্রুত শুরু

### 1. রিপোজিটরি ক্লোন করুন

```bash
git clone https://github.com/Moniruzzamanmonir5281/quotex-signal-bot.git
cd quotex-signal-bot
```

### 2. নির্ভরতা ইনস্টল করুন

```bash
pip install -r requirements.txt
```

### 3. পরিবেশ সেটআপ করুন

```
cp .env.example .env
```

এবং আপনার Quotex API শংসাপত্র যোগ করুন:

```
QUOTEX_EMAIL=your_email@example.com
QUOTEX_PASSWORD=your_password
QUOTEX_API_KEY=your_api_key
```

### 4. বট চালু করুন

```bash
python main.py
```

## ⚙️ কনফিগারেশন

`config.py` ফাইলে সমস্ত সেটিংস কাস্টমাইজ করুন:

```python
# ট্রেডিং
TRADE_AMOUNT = 10           # প্রতিটি ট্রেডে ডলার
ASSETS = ['EURUSD', ...]   # ট্রেড করতে সম্পদ
CHECK_INTERVAL = 60         # চেক করা ফ্রিকোয়েন্সি

# ঝুঁকি
MAX_DAILY_LOSS = 100        # সর্বোচ্চ দৈনিক ক্ষতি
MAX_TRADES_PER_DAY = 10     # সর্বোচ্চ দৈনিক ট্রেড

# সূচক
SMA_SHORT = 10              # স্বল্পমেয়াদী SMA
SMA_LONG = 20               # দীর্ঘমেয়াদী SMA
RSI_PERIOD = 14             # RSI সময়কাল
```

## 📊 কিভাবে এটি কাজ করে

1. **বাজার বিশ্লেষণ**: বট নিয়মিত বাজারের ডেটা বিশ্লেষণ করে
2. **সিগনাল তৈরি**: একাধিক সূচক ব্যবহার করে ট্রেড সিগনাল জেনারেট করে
3. **চূড়ান্ত সিগনাল**: সমস্ত সূচক মতামত একত্রিত করে চূড়ান্ত সিগনাল তৈরি করে
4. **শক্তিশালী সিগনাল**: শক্তিশালী সংকেত দেখলে ট্রেড সম্পাদন করে
5. **বিজ্ঞপ্তি**: টেলিগ্রামে আপডেট পাঠায়
6. **দৈনিক রিপোর্ট**: প্রতিদিন সারসংক্ষেপ প্রদান করে

## 🔒 নিরাপত্তা

⚠️ **গুরুত্বপূর্ণ**: কখনও আপনার API কী বা পাসওয়ার্ড শেয়ার করবেন না।

- `.env` ফাইল `.gitignore` এ রয়েছে
- পাসওয়ার্ড পরিবেশ ভেরিয়েবলে সংরক্ষিত
- কোনও সংবেদনশীল ডেটা লগ করা হয় না

## ⚠️ ঝুঁকি সতর্কতা

ট্রেডিং ঝুঁকিপূর্ণ এবং আর্থিক ক্ষতির কারণ হতে পারে।

- এটি শিক্ষামূলক টুল - সম্পূর্ণ স্বয়ংক্রিয় নয়
- সর্বদা ঝুঁকি পরীক্ষা করুন এবং মনি ম্যানেজমেন্ট প্রয়োগ করুন
- ডেমো অ্যাকাউন্টে প্রথম পরীক্ষা করুন
- শুধুমাত্র আপনি হারাতে পারেন তাই বিনিয়োগ করুন
